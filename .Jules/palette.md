## 2024-05-17 - App Logo and Link Accessibility
**Learning:** Default Create React App boilerplate has a generic "logo" alt text and lacks an aria-label on the main link. While seemingly minor, a more descriptive alt text (like "React logo") and a clear aria-label on links (like "Learn more about React") improve screen reader experience on landing pages.
**Action:** When working on React applications, ensure boilerplate code is updated to include more descriptive alt text for logos and aria-labels for primary links.
