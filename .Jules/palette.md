## 2024-03-01 - Add Focus Styles to Links
**Learning:** Default browser focus outlines are sometimes suppressed or styled in visually indistinguishable ways (especially on dark backgrounds). Providing explicit `focus-visible` styles enhances keyboard accessibility significantly. Adding smooth hover states also provides interaction feedback.
**Action:** Always add explicit hover and focus-visible outlines with proper contrast (e.g., using `outline-offset` and complementary colors) to interactive elements like links and buttons when setting up CSS.
