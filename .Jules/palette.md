## 2024-05-24 - [External Link Context]
**Learning:** Adding `aria-label="[Link Text] (opens in a new tab)"` is a critical accessibility pattern for links with `target="_blank"`. It ensures screen reader users are not disoriented when a new window opens.
**Action:** Always verify `target="_blank"` links have appropriate context via text, `aria-label`, or visually hidden text to warn users.
