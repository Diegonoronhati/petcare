## 2024-11-06 - [Boilerplate Component Accessibility]
**Learning:** Default boilerplate components in frameworks like Create React App often lack robust accessibility attributes out of the box, such as specific alt text and context for external links (which can be disorienting for screen reader users when they open in new tabs).
**Action:** Always verify generated boilerplate for a11y fundamentals: replace generic alt text with descriptive ones, and add aria-labels indicating when a link opens in a new tab.
